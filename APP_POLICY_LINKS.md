# App policy links — live website versions

Index of the **live website versions** of each app's privacy and terms documents, served from this repository (`Persie0/legal`) at `https://persie0.github.io/legal/…` — not the GitHub blob links and not the separate older privacy website.

- **Privacy policy (live):** the German `DATENSCHUTZ.md` and English `PRIVACY.md` drafts are served from this repository at `https://persie0.github.io/legal/references/eu-app-legal/app-policies/<app-slug>/` — e.g. the English privacy policy for Background Noise Remover is https://persie0.github.io/legal/references/eu-app-legal/app-policies/background-noise-remover/PRIVACY.md
- **Terms of Service, German (live):** https://persie0.github.io/legal/terms/<app-slug>/ — the Pages-rendered `NUTZUNGSBEDINGUNGEN.md` (Jekyll permalink).
- **Terms of Service, English (live):** https://persie0.github.io/legal/terms/<app-slug>/en/ — the Pages-rendered `TERMS.md` (`legal_kind: terms-en`).

GitHub Pages must be enabled for this repository (branch main, root) before these URLs resolve. The linked drafts are unpublished working texts and not legal advice.
