# App policy links — repository drafts

Canonical index of every app's privacy and terms documents: this file is the single place to look up the current versions, and the table links directly to the documents in this repository (`Persie0/legal`). All 32 apps have both languages:

- **Privacy policy:** `DATENSCHUTZ.md` (German) and `PRIVACY.md` (English) — `references/eu-app-legal/app-policies/<app-slug>/`
- **Terms of Service:** `NUTZUNGSBEDINGUNGEN.md` (German) and `TERMS.md` (English, `legal_kind: terms-en`) — same folder

These repository drafts are the current working versions. Future live website versions will follow once GitHub Pages is enabled for this repository: German terms at `https://persie0.github.io/legal/terms/<app-slug>/`, English terms at `https://persie0.github.io/legal/terms/<app-slug>/en/`; the separate privacy website (`https://persie0.github.io/privacy/`) still shows the older policy texts.
