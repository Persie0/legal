# App policy links — live website versions

Index of the **published website versions** of each app's legal documents. These are the URLs to use in apps, store listings and support pages — not the draft files in this repository.

- **Privacy policy (live website):** hosted on the separate policy website at https://persie0.github.io/privacy/<app-slug>. **Note:** the live privacy pages still show the older policy texts; the restructured German drafts (DATENSCHUTZ.md) and the English drafts (PRIVACY.md) in this repository have not yet been published there.
- **Terms of Service, German (live website):** https://persie0.github.io/legal/terms/<app-slug>/ — served from this repository via GitHub Pages (NUTZUNGSBEDINGUNGEN.md).
- **Terms of Service, English (live website):** https://persie0.github.io/legal/terms/<app-slug>/en/ — served from this repository via GitHub Pages (TERMS.md, legal_kind: terms-en).

GitHub Pages must be enabled for this repository (branch main, root) before the /legal/terms/… URLs resolve. The English drafts are, like the German drafts, unpublished working texts and not legal advice. Apps marked “—” have no live privacy page yet (12 of 32: Boost Phone Audio Volume, DoubleTapKing, EarnMeter, Finger Chooser, MoWa, Neon Snake, Photo Print Size Editor, Recipe Price Calculator, Selfie Diary, UniMinder, VPN & Proxy Detector, Video Upscaler Offline (macOS)).
